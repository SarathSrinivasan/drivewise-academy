# DriveWise Image Guide

Every public page has its own automotive image collection. The same image URL is not intentionally reused between public pages.

The Home page includes an automatic right-to-left vehicle marquee that pauses on hover and respects reduced-motion preferences.

Instructor profiles retain portrait photography while their page hero/gallery uses a separate vehicle collection.

When adding new imagery, keep it relevant to the section and assign a new URL to avoid cross-page repetition.
